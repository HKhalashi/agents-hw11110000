# Проектирование

## Модель данных
Каждая задача представлена объектом `{ id: number, title: string, hours: number, done: boolean }`. Состояние хранится в массиве в памяти браузера. При запуске создаётся заданный исходный набор задач.

## Расчёты
- `totalHours` — сумма `hours` всех задач.
- `completedHours` — сумма `hours` только задач с `done === true`.
- `progress = totalHours === 0 ? 0 : Math.round(completedHours / totalHours * 100)`.
- Фильтрация применяется только к отображаемому списку и не меняет массив, по которому рассчитываются показатели.

## Валидация
Название обрезается через `trim()` и должно содержать хотя бы один непробельный символ. Перед преобразованием часов в число необходимо проверить исходную строку, чтобы пустое значение не стало нулём. Допустимый диапазон — 0,5–24 включительно, шаг — 0,5. При ошибке отображается сообщение у поля, форма не очищается.

## Интерфейс
Один HTML-файл содержит семантическую разметку, встроенные CSS и JavaScript. Используются подписи полей, доступные имена кнопок и чекбоксов, видимый текст ошибок и адаптивная компоновка. На узком экране поля формы располагаются вертикально, элементы списка не выходят за ширину окна.

## Хранение
Сохранение между перезапусками не реализуется. В задании localStorage является необязательным улучшением; основная приёмка от него не зависит.
