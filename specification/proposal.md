# Предложение: мини-трекер учебных задач

## Цель
Создать небольшое автономное браузерное приложение для учёта учебных задач на неделю и измерения выполнения по оценке в часах.

## Входит в объём
- Показ исходного примера из трёх задач.
- Добавление задачи с названием и оценкой в часах.
- Переключение отметки «готово» и удаление задачи.
- Фильтр списка: все / активные / готовые.
- Отображение суммарных часов, выполненных часов и процента выполнения по часам.
- Проверка ввода с сообщениями об ошибках рядом с соответствующими полями.
- Читаемость при ширине окна 390 CSS-пикселей без горизонтальной прокрутки.

## Не входит в объём
Сервер, учётные записи, синхронизация, внешние библиотеки, CDN, API-ключи, сборка и сохранение данных между перезапусками. localStorage указан в задании как необязательное улучшение и намеренно не реализуется.

## Результат
Один автономный файл `tracker-v2.html`, содержащий CSS и JavaScript.
