# Домашнее задание № 1 — вариант A

**Тема:** мини-трекер учебных задач.  
**Подходы:** прямое задание и разработка по спецификации.

## Состав работы

- `tracker-v1.html` — первая реализация по короткому прямому заданию.
- `tracker-v2.html` — вторая реализация после подготовки спецификации.
- `specification/` — четыре документа второй попытки: `proposal.md`, `specs/tracker/spec.md`, `design.md`, `tasks.md`.
- `prompts.txt` — тексты заданий и запросов, использованных для подготовки версий.
- `report.md` — методика, результаты, сравнение и ограничения.
- `test-evidence.md` — сводка автоматизированных браузерных проверок.
- `screenshots/` — снимки обеих версий при ширине 1280 px и 390 px.

## Запуск

Скачайте `tracker-v1.html` или `tracker-v2.html` и откройте файл в современном браузере. Приложение автономное: сервер, установка библиотек, интернет и API-ключи не требуются.

## Исходные данные и контрольные значения

- «Чтение» — 2 часа, выполнено.
- «Практика» — 4 часа, активно.
- «Повторение» — 2 часа, активно.

Исходный итог: 8 часов, выполнено 2 часа, прогресс 25%. После отметки «Практика» выполненной: 6 из 8 часов, прогресс 75%.

## Методологическое примечание

В задании для варианта A предписаны два новых независимых диалога с одной моделью. При подготовке представленных файлов обе реализации были созданы в рамках одной рабочей сессии; требование об отдельных независимых диалогах не выполнено. Это ограничение прямо отражено в отчёте и не должно трактоваться как независимый эксперимент. Спецификация подготовлена в формате OpenSpec; OpenSpec CLI и валидатор не запускались, что допустимо для варианта A.
